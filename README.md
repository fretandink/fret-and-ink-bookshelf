# Fret and Ink — Bonus Content Bookshelf

This is the Fret and Ink member Bonus Content bookshelf: an interactive
pop-art bookshelf with seven playable music games (Music Crosswords, Music
Word Search, Mad Libs, Word Scramble, I-Spy, Memory Match and Jigsaw).
It is hosted here on GitHub Pages and shown inside the Fret and Ink Wix
site's member-only Bonus Content page in an iframe.
